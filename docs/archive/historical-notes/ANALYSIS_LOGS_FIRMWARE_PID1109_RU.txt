Вывод по логам
--------------
1. Universal Analog Plugin загрузился штатно:
   - ABI1;
   - SDK initialise result=0;
   - transport_error=0;
   - 225 успешных poll-вызовов;
   - завершение без аварии.

2. UAP не публиковал устройство PID 1109:
   - dense_devices=0;
   - count=0.
   Это ожидаемо для dedicated native build, где VID 373B/PID 1109
   исключается из UAP до CreateFileW.

3. Одновременно был запущен другой backend:
   - protocol=madlions-a0-passive;
   - profile=madlions-a0-fw-1109;
   - usage=0001:0000;
   - samples=0 за весь сеанс.

4. Строки protocol=madlions-a0-passive отсутствуют в исходниках
   HallJoy MAD68 Pro R Native Stable. Следовательно, тест выполнен
   не специализированным HallJoyMAD68ProRNative.exe либо другим
   ранее собранным target.

5. Правильный firmware-specific backend обязан:
   - создать HallJoyMAD68ProR.log;
   - записать backend worker start build=MAD68ProR-Native-Stable-v3.5;
   - выполнить безопасную последовательность A9 -> A8 -> A9;
   - принимать A0-пакеты и публиковать реальные значения 0..1600.
