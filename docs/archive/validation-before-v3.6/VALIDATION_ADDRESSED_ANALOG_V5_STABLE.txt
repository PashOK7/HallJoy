HallJoy Addressed Analog v5 Stable Clean — validation report

Scope
- Removed the obsolete single-last-key legacy backend from source, project, settings and UI.
- Hardened addressed 0x94/02 response recovery.
- Added cancellable/bounded HID reader shutdown.
- Simplified production analog-host supervision and shutdown.
- Reduced normal log cadence while preserving anomaly context.

Legacy backend removal
- backend_aula.inc does not exist.
- HallJoy.vcxproj and HallJoy.vcxproj.filters contain no backend_aula reference.
- backend.cpp/app.cpp contain no legacy ownership or read path.
- AulaCommMode setting and INI persistence are absent.
- Obsolete safety validator requiring the deleted worker was removed.

Addressed transport recovery
- One absent 28 ms response no longer terminates the session.
- Recovery limit: 8 consecutive fully missed transactions or 1000 ms without a valid response.
- Pending request token is cleared after a miss so a late packet cannot terminate the session.
- Late responses and recovered misses are tracked separately from invalid protocol responses.
- Recovery exhaustion saves the bounded 256-transaction trace and reconnects.

Reader shutdown
- Active reader HANDLE is registered under a mutex.
- AddressedAnalog_Stop and device-change notification call CancelIoEx.
- RunSession waits 750 ms for reader exit.
- If cancellation does not complete, the HID handle is closed and another bounded wait is performed before join.
- Reader exit is signalled by a dedicated manual-reset event.

Analog-host process lifecycle
- Release build sets kUseChildDebugger=false.
- DEBUG_ONLY_THIS_PROCESS is selected only by a compile-time diagnostic branch.
- Production supervisor waits on the child process handle instead of WaitForDebugEvent.
- TerminateThread was removed from supervisor and snapshot-bridge shutdown.
- Shutdown uses cooperative stop events, child job termination as fallback, and bounded waits.
- If a third-party plugin thread still refuses to stop, shared resources are left intact for OS process teardown rather than being unmapped underneath a live thread.
- Parent lifecycle markers are appended to HallJoyAnalogHost.log.

Logging
- HallJoyAddressedAnalog.log aggregate cadence remains 10 seconds and is capped at 2 MiB.
- HallJoyAddressedAnalogTrace.log is anomaly-only and bounded to 256 recent transactions.
- HallJoyAnalogHost.log periodic stats cadence changed from 2 seconds to 10 seconds.
- Child start/exit, restart, supervisor mode and shutdown completion are event-logged.
