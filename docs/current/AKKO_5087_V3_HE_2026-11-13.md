## Implemented route and safeguards

Exact3131 on3151:5029 now has a native read-only snapshot model. Two consistent
8F identities precede E6 precision metadata and four E5/FE proof pages. Zero is a
valid sample. Unknown E6 replies fall back to the manufacturer's legacy version
scale; an explicit unknown precision enum cannot be converted. No 1B monitor,
calibration-start, flash write or settings write is selected. Shared-buffer request
poisoning distinguishes pending/echo replies; physical-slot bounds ignore empty
nonphysical positions. Actual feature framing/transfer failures remain failures.

The factory map is authoritative for physical positions. Optional84/8A metadata
provides current assignments; malformed, missing or incomplete metadata falls
back to factory positions, without applying a partial remap. Disabled/duplicate/
unknown assignments do not reject the87 physical channels. Layout-cache failure
cannot veto the safe source. A display-only calculator does not invalidate auto
selection. The preset contains88 visible controls /87 analog keyboard positions.
Generic Menu geometry uses exact factoryHID231 at that physical position; current
assignments can still remap it. This is model-specific producer data, not an
assumption from the generic Common87 caption.

Successful Akko pages have no inserted polling delay. Invalid pending replies use
bounded I/O readiness retries, not an arbitrary tester hold/idle schedule. Native
telemetry averages a complete four-page sweep for Akko, while update counts count
pages. A sweep samples pages sequentially, not as one atomic physical scan.
The paged Shark worker yields ownership after the exact paired snapshot identity.
Unrelated board/USB identities are remembered until device-topology notification;
transient busy/I/O failures remain retryable. Pause/stop cancels pending I/O,
closes the exclusive handle and clears both factory and assigned publications.

Ordinary HallJoy.log retains admission/read/cleanup stages, command/page and
Win32 error, partial/envelope diagnostics and unsupported scale. Its independent
cached collector runs on the log worker and preserves the Viper collector. It
reports all page counts, observed channels, changed/positive/released channel
counts, current/maximum aggregate activity and peak depth units. No keyboard
text, raw key stream, paths, serials or vendor buffer dump is added. Pending
release observation stays explicit if no press/release has been observed.

Hard refusals and executable cases: foreign board/USB tuple; inconsistent paired
identity; wrong feature collection; open failure; unsupported explicit precision;
out-of-scale physical depth; unprocessed echo; short feature transfer; actual
ownership collision; cancellation. Optional assignment count/content/version/
layout-cache variations are metadata-only. The exact compiled production session
is exercised through isolated private named pipes, with no physical HID opened.
The source/firmware tests do not establish real USB timing or exact3131 ADC/filtering.
