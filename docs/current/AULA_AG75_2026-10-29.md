## Layout source

The driver draws every board from the keyboard's row/column code table on a
generic template, so it has no static geometry. Source: the official top view on
the AULA AG75 product page (aulastar.com, image
`https://www.aulastar.com/uploads/allimg/20260616/1-260616115153547.png`,
SHA-256 `310c3c42...`, the "75%" Ultra/orange photo; local copy in
`.local/research/aula-ag75-20261029/web/`):

- 81 keys, ANSI; Esc, F1-F4 / F5-F8 / F9-F12 in groups with 0.25u gaps, Home and
  End top right; Backspace 2u + Delete; Tab 1.5u, `\` 1.5u, PgUp; Caps 1.75u,
  Enter 2.25u, PgDn; Shift 2.25u / 1.75u, Up; Ctrl, Win, Alt 1.25u, Space 6.25u,
  Fn and Ctrl 1.25u, arrows. No right Alt. The capsule right of Up is a mode
  switch, not a key. Rows 2-6 equal Weikav EG75 HE; the F-row differs.
- The keyboard reports its own codes, so a legend that differs from the code table
  only affects the drawing, not input.
