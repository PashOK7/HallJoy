# Заметки по ложному срабатыванию антивируса

Изменения v5, уменьшающие подозрительные эвристические признаки:

- production child-host запускается без `DEBUG_ONLY_THIS_PROCESS`;
- supervisor не использует debugger API в обычной Release-сборке;
- `TerminateThread` удалён из остановки analog-host supervisor и snapshot bridge;
- отсутствуют packer и обфускация;
- отсутствует сетевое скачивание или запуск внешнего payload;
- runtime DLL собираются из включённых исходников.

Что остаётся нормальным, но иногда влияет на репутационные детекты:

- приложение неподписано;
- создаёт изолированную дочернюю копию самого себя для защиты основного UI от сбоев plugin;
- работает с HID, hooks, виртуальным gamepad и shared memory;
- имеет малую распространённость нового хеша.

Для проверки релизного EXE необходимо сохранять точный SHA-256 и результат VirusTotal. Один детект без названия сигнатуры нельзя считать подтверждением вредоносности или подтверждённым false positive.
