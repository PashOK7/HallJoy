## Exact code cause

src/HallJoyProject/HallJoy/irok_hz94_profile.h: MapEvidence::Admitted requires
assigned >= 60 AND outside == 0. InspectMap counts a nonzero device assignment in
an empty exact factory-map position as outside. Therefore the logged 104/94/10
map fails admission despite all 94 factory assignments matching.

src/HallJoyProject/HallJoy/irok_na87_backend.cpp: ReceiveMap records these counts
and immediately returns false when the HZ-94 map is not admitted. Prove then
fails before EnsureClaim/Run; Run contains the later volatile analog subscription.
Thus this trial stops at HallJoy's map validation, before attempting the analog
stream. The log establishes this refusal, not just an inference from zero updates.

The 104 assignments do not establish a physical 104-key keyboard: ten values are
in table positions absent from the exact 94-key geometry. Their meanings/bytes
are not recorded in this report. They could be nonphysical/default/alternate
slots; this is unproven and must not be presented as firmware corruption.
The other backend's W669 failures/start-refused state is not the HZ-94 path.
