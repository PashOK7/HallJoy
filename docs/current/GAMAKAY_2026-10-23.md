## Result

TK75 HE V2 = boards **3138** (UK/ISO) and **3167** (US). This settles the open question of 2026-09-24
(NEO65_AND_PROTOCOL_EXPANSION_2026-09-24.md: "3138/3167 still not mapped conclusively to HE V2"). Both are in the
pinned Womier 3.2.15 RongYuan catalog with `known_stream_parent` (7a5b12c9.js, the same parent as the implemented
TK75 HE / TK75 TMR) and `matrix_available`, so they can be added to the existing RongYuan stream like the other
GamaKay boards (exact board admission, factory matrix, yellow notice). Implemented the same day (section below).
TK68 HE: no identity or firmware found; needs a user HallJoy.log.
