# IROK MG75 Max / Pro: раскладки

2026-09-13 владелец явно запросил добавление этих двух моделей, возобновив
работу над раскладками. Добавлены IROK MG75 Max ANSI и IROK MG75 Pro ANSI,
по81 клавише, в общий каталог IROK. Визуальную оценку выполняет владелец.

Геометрия извлечена статически из закреплённого официального
https://hid.irok.cn/assets/index-BQvZQSA6.js, SHA256
2b80dd9398565e13ebf315351af96c3bfcf059fa917a774638b0be42c69c44dc.
Источник сохранён в docs/research/irok-mg75-layout-sources/.
MG75 Pro: hDt extends W5t extends Oc; Max: wDt. Оба используют порядок Qn,
но различаются customLayout: Caps, Enter, Shift и отдельные размеры/отступы.
Размер базовой клавиши36.5 нормализован до42. Координаты воспроизводят APt:
сумма левых отступов/ширин и максимальная высота каждой строки. Скрипт не
исполняет JS производителя и не обращается к HID.

Повторяемое извлечение: python tools/build_irok_mg75_layouts.py
Проверка: python tools/layout_pipeline.py check IROK
Reviewed reports подключены через tools/layout_catalog.json;
интеграция общим layout_pipeline.py integrate. Старые массивы геометрии
байтово сохранены как префикс; таблица идентификации не изменилась.

Выбор вручную в Layout / Brand IROK. Новый автоподбор по общему VID/PID не
добавлялся: текущий SparkLink не публикует подтверждённую точную модель
для этих двух пресетов. Сохранённые пользовательские раскладки не заменяются.
Поддержка аналога Max/Pro и NA87 backend этим изменением не расширялась.
MG75 v2 не добавлена: это другая неподдерживаемая ревизия.

Fn отображается с зарезервированным кодом HallJoy0x409. Текущая SparkLink
таблица ограничена byte HID и не публикует этот расширенный код; не обещать
аналоговый индикатор Fn. Стандартные клавиши используют обычные USB HID usages.

Проверки исходника/отчётов, уникальности HID,81 клавиши, пересечений геометрии,
общие static audits и MSVC Release/x64: PASS. Только прежний ViGEm LNK4099.
