## Рабочий ввод

Новый descriptor IrokNa87M484 включён в общий native registry до UAP.
Точный интерфейс0416:7372 / FF1B:0091 / reports64/64 получает ownership только
после M484/GK8260HERGB, capability40 и полной корректной карты6x22 от устройства.
Не используется карта ND75, Pro или совпадение одного VID/PID как доказательство.
Проверенный shared WriteFile route; exclusive и control-write переборы не запускаются.
Настройки, калибровка и прошивка не записываются.

Карта читается командой0x10: строки1–5 и terminal FF:FF для шестой строки.
Проверяются полнота, повторные конфликтующие строки, уникальность HID и границы.
Карта тестировщика содержит90 позиций, включая три дополнительных ISO/JIS usages;
это не утверждение о90 физических клавишах. Подтверждённая ANSI геометрия имеет87.
На соединении карта читается заново; неверная карта блокирует публикацию.

После unsubscribe устанавливается постоянная подписка на позиции карты.
Только проверенный envelope события0x21/03/01, координаты6x22 и глубины0–40
публикуются в диапазоне0–1000 через общий native registry. Индикаторы, overlay,
кривые, бинды и геймпад используют этот общий маршрут. Обновление одной позиции
не сбрасывает остальные; нулевая глубина отпускает только соответствующую клавишу.
Пользовательские профили и бинды не перезаписываются.

Pending overlapped read остаётся активным при ожидании без событий. При закрытии
он отменяется и дожидается завершения до освобождения буфера/handle. Раз в секунду
проверяется identity; отсутствие подтверждения3 секунды или transport loss обнуляет
состояние и запускает reconnect. Неподвижное удержание само по себе не обнуляется.
Остановка/потеря соединения снимает ownership и значения.

Раскладка IROK / IROK NA87 Mag ANSI доступна в каталоге. Первый запуск использует
существующее правило единственного подтверждённого источника. Сохранённый/manual
выбор не заменяется; при необходимости пользователь выбирает новую раскладку сам.

## Диагностика и публичный лог

Вывод работает непрерывно. Статус analog connected появляется после подключения.
После30 секунд при8 разных аналоговых нажатиях/отпусканиях и2 одновременно статус
становится diagnostic data collected. После60 секунд при недостатке покрытия —
limited diagnostic coverage. Ни один из этих статусов не выключает аналог.
В лог раз в секунду попадают агрегаты: счётчики, активные позиции, интервалы,
отпускания, ошибки диапазона/связи; при завершении — session summary.

Путь результата прежний: один HallJoy.log рядом с EXE. UI/логи/новые комментарии
на английском. Отдельный ZIP или скрипт пользователю не нужен.
Новый вариант не собирает raw digital transitions, сырые vendor packets,
ContainerId, стабильные path hashes и per-key coverage. Plain log допускает только
агрегаты нового NA87 backend. Structured sink редактирует пути, профили, хеши,
отдельные HID-коды и checkpoint значений. Проверка с приватными sentinel-строками
прошла. Старые логи этой защитой задним числом не очищаются.
Остаются обычные технические метаданные: время, версия, коды ошибок, счётчики.

## Ограничения доказательств

Аппаратный лог доказал поток глубин, но не полноту всех событий при сочетаниях.
Кеш событий не может восстановить глубину из события, которое прошивка не прислала.
Удержания не заменяются выдуманным timeout-release, цифровые клавиши не выдаются
за аналог, нулевые control snapshots не считаются подтверждённым полным состоянием.
Физический прогон нового backend и влияние периодической identity на stream
ещё должен проверить тестировщик. Самотест доказывает обработку доставленных
событий в коде, не гарантирует без потерь работу физической прошивки.

По вопросу владельца о полном снимке: были4 GetInputReport чтения примерно
за150 мс, а не одно. Если клавиши в этот момент отпущены, нули возможны.
Однако последние цифровые события в логе — четыре нажатия без следующих отпусканий;
лог не подтверждает гипотезу об отпущенных клавишах в момент чтения. По этим ответам
нельзя ни доказать полезный полный снимок, ни исключить его получение вообще.
Новая рабочая версия использует подтверждённые события, без параллельного snapshot
эксперимента, который мог бы вмешаться в поток.
