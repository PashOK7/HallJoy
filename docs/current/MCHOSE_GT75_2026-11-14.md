Inputs/results/assessment pinned privately. Boundaries: writer5688..578A,

-04 reads base6F000;05 reads settings65000 with volatile byte32 projection
  per64-byte record. Boot ignores count and unused base magic; effective
  current/table entries above3 fall back to0. HallJoy follows that behavior.
-06 writer persists a4096-byte sector RMW, then reloads active profile. Only
  debug bit3 of byte7 changes in saved data. The real active RAM byte1 mask0x0e
  remains a source behavior. Reset-armed settings[0]&1 prohibit automatic writes.
  The poll-rate byte4 is preserved; calibration and map writes are never sent.
-A0 stream carries immutable physical descriptor, big-endian depth6:7 and
  declared maximum14:15. ServiceCB4C compares independent caches across96 slots;
 81 are magnetic, includingFn descriptor F0FF01. Consumer/function slots outside
  this scan are not fabricated analog inputs.
-Firmware zeroes depths<=9 and snaps depth>=maximum-5 to full. HallJoy divides
  by the actual frame maximum and introduces no smoothing, rate cap, guessed
  digital release or per-key expiry. A quiet changed-only channel retains its
  last measured value while the source is online.
-Physical USB loss, typing coexistence and sensor calibration upstream of the

## Production implementation

Dedicated protocol36 `mchose-gt75`; exact target only, no MI-number hard gate.
Actual analog sample (including zero) establishes connected state. Device info,
version, base count, missing map/cache and unrelated metadata never veto passive
read. Invalid stored profile or reset-armed state veto the unsafe write only;
the exact opened target remains listening for genuine A0 input.

The session changes at most one debug bit per attachment attempt, checks whole
saved readback ignoring firmware's volatile projection, and accepts verified
readback after a lost ACK. On stop it clears only its own attempted0->1 flag,
including the original profile after a profile switch. Pre-enabled flags remain.
Cleanup exchanges are bounded and can complete after cancellation; unavailable
state is logged rather than guessed. Process crash/power loss can leave the
persistent debug flag enabled. No automatic restore of an unknown prior flag.

Exclusive HID transport; unrelated USB notifications retain pending reads/held
depths. Device/profile changes neutralize and re-admit. No flash retry loop after
an ambiguous enable; no user-visible extra scripts or timed test stages.

Exact preset **MCHOSE GT75 ANSI** has81 magnetic keys (Fn included) plus2
display-only RT controls from manufacturer geometry. Both pending preview and
live automatic selection use GT75-3837-302D-ANSI. A0 identifies factory physical
positions; this trial publishes those positions, not unverified saved logical
remaps. No vendor geometry code/artwork is embedded.
