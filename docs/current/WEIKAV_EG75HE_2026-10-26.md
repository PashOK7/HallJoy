## Layout source

The SparkLink driver has no static layout file: it asks the keyboard for its row/column code
table (`03 01`, 6 x 21 HID codes, no widths or gaps) and draws it on one generic 75% template
(the same F-row spacing as the SU75 Pro screenshot). Same method as Everglide SU75 Pro
([EVERGLIDE_SU75PRO_2026-10-02.md](EVERGLIDE_SU75PRO_2026-10-02.md)):

- Key assignments: driver screenshot `https://weikav.com/wp-content/uploads/2026/06/driver.jpg`
  (SHA-256 5aaa7c95...), "EG75" connected: Esc, F1-F12, Insert; Delete, PgUp, PgDn right column;
  right Shift 1.75u, Up, nothing right of Up; bottom Ctrl, Gui, Alt, Space 6.25u, Fn1, R-Ctrl,
  arrows.
- Physical geometry: retail top view `https://weikav.com/wp-content/uploads/2026/06/main-1-1.jpg`
  (SHA-256 22d1754f...): 80 keys, ANSI, F1/F5/F9 at 1.5u/6u/10.5u (0.5u gaps), Insert at 15u,
  Backspace 2u, 1.25u bottom-row modifiers, 0.5u gap before the arrows.
- Only difference: the retail keycaps right of Space read ALT and FN, the driver key map reads
  Fn1 and R-Ctrl. HallJoy receives the keyboard's codes, so the layout follows the driver map
  (Fn = HallJoy 0x409 / SparkLink 0xF101, R-Ctrl = 228).
