# Экспорт совместимости HallJoy

`HallJoy_supported_keyboards.xlsx` — снимок на 2026-09-09, подготовленный по
`SUPPORTED_HARDWARE.md`, закреплённому коду Soup/UAP и отчёту исследования X68 HE.
Три листа: поддерживаемые модели/варианты/семейства, неподдерживаемые устройства,
пояснения. Строки семейных маршрутов не считаются отдельными моделями.

Указаны статусы проверки, ограничения прошивок, USB-идентификация и пути источников.
Замороженные кандидаты не включены в поддерживаемые. Addressed Analog остаётся
рабочей поддержкой; экспорт ничего не меняет в приложении или настройках.

Воспроизведение: `py docs/exports/export_keyboards.py`. Генератор стандартной
библиотеки Python создаёт настоящий XLSX с фильтрами, закреплённой строкой,
переносом текста и чередованием фона. Проверяет источники, дубликаты, XML и ZIP.
Не перезаписывает существующий файл: перед обновлением проверить изменения и
сохранить предыдущую версию. Это вручную сверенный снимок, не автообещание
совместимости каждой клавиатуры с похожим названием.
