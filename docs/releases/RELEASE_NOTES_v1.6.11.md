# HallJoy 1.6.11

- DrunkDeer A75 Ultra: key travel is now read with the keyboard's own tracking
  format. Before, HallJoy read it like older A75 boards: key depth was scaled
  wrongly (full press too early) and the connection could be reported as
  unstable. Hardware testing is
  incomplete; please report how it works. There is no built-in A75 Ultra
  layout yet: choose DrunkDeer A75 ANSI in the layout list.
- DrunkDeer A75, A75 Pro and A75 ISO with newer firmware (high-precision
  mode): key travel now uses the 0.01 mm scale of that firmware, so keys no
  longer reach full press too early.
- MonsGeek FUN60 Ultra TMR: the board revision on USB 3151:5030 now connects.
  It uses the same key map and built-in layout as the supported revision.
