# HallJoy 1.6.2

- Added full wired USB support for ATTACK SHARK R85 HE and AJAZZ AK820 MAX RGB.
- Fixed ATTACK SHARK keyboards failing to connect when exclusive device access is unavailable.
- Fixed repeated virtual gamepad restarts triggered by Windows device notifications during startup.
- Added experimental wired USB support for Chilkey Slice75 HE, EPOMAKER G84 HE and MonsGeek M1 V5 HE, including automatic layouts, analog bindings and virtual gamepad output.
- Improved keyboard connection diagnostics.
- Remember the last automatically selected keyboard layout to avoid showing a different layout during startup and keyboard reconnection.
