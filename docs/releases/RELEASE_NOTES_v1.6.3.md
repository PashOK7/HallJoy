# HallJoy 1.6.3

- Significantly expanded experimental analog keyboard support. See the [full keyboard list and support statuses](https://docs.google.com/spreadsheets/d/1ueQ4labXpuBOmGjCkUcJllNJ68Jzx4py2MuQm-p-R7c/edit#gid=0).
