Implementation contract
-----------------------
- Initial ViGEm client/target creation remains on the startup thread.
- After output-worker start, it exclusively owns update, reconnect and destroy.
- Realtime performs only a try-publish to LatestValueMailbox and an event wake.
- Pending valid-pad masks merge; payloads come from the newest complete snapshot.
- Emergency neutralization drops older queued reports and submits neutral last.
- Stop waits at most 3000 ms. Timeout retains handles and driver ownership,
  blocks dependent backend teardown and selects process exit code 2.
- --halljoy-test-vigem-update-stall exists only under
  HALLJOY_ANALOG_SIMULATOR and sleeps 60000 ms before the first simulated update.
