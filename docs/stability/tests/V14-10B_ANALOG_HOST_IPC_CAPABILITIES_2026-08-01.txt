Scope
-----
- Remove named mapping/events from the isolated analog-host transport.
- Pass only four unnamed kernel capabilities to the created child through an
  explicit process handle list.
- Bind shared schema v10 to owner PID and a CSPRNG launch token.
- Validate inherited handles and both child/parent identity directions.

Implementation contract
-----------------------
- Parent creates an unnamed mapping, unnamed manual stop event, unnamed
  auto-reset snapshot event and a real owner-process handle.
- STARTUPINFOEXW plus PROC_THREAD_ATTRIBUTE_HANDLE_LIST limits inheritance to
  those four handles. CreateProcessW enables inheritance only for that list.
- Child uses inherited handle values directly. It contains no
  OpenFileMappingW, OpenEventW or Local\HallJoyAnalog name path.
- Child validates every handle, schema magic/version/size, owner PID, CSPRNG
  launch token and GetProcessId(owner handle) before publishing.
- Parent accepts Ready only when shared hostPid equals the PID returned by its
  own CreateProcessW call.
