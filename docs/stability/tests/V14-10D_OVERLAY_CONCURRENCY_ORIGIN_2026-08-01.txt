Implementation contract
- Fixed 16-slot socket/thread ownership table; accept delegates but never
  blocks on client-controlled reads.
- Every client worker uses the common C++ exception barrier.
- Stop shuts down all client sockets and waits for every client worker before
  WSA cleanup. Join timeout retains reachable ownership and poisons restart.
- Saturation attempts best-effort HTTP 503 and always closes promptly. Winsock
  may expose a reset when the rejected request remains unread; the accept owner
  intentionally does not drain attacker-controlled input.
- Every server generation creates a 128-bit token via BCryptGenRandom.
- Root bootstrap sends HallJoySession with HttpOnly and SameSite=Strict.
- /state and /client_perf require the exact cookie.
- An open page handles a stale-generation 401 by fetching root once for the
  new HttpOnly cookie, then resumes polling without a manual refresh.
- Browser Origin must exactly equal http://127.0.0.1:<bound-port>; only that
  origin is echoed with Vary: Origin. Wildcard CORS is absent.
