HallJoy V14-11A UAP poll pacing evidence
Date: 2026-08-01
Workstation device: Irok MG75 Max, VID 1CA6, PID 0529, usage page FFB0

Scope
-----
Replace zero-delay private-UAP vendor polling with transport-scoped deadline
pacing. This evidence does not claim UAP hardware verification because the
available Irok keyboard uses HallJoy's native SparkLink route.

Implementation contract
-----------------------
- All six private UAP .sun targets define UAP_POLL_TARGET_US=1000.
- Only AnalogueKeyboard::isPoll() workers enter the pacing branch.
- Successful fast transactions wait only to the 1 ms start-to-start deadline.
- Successful transactions at or beyond the deadline receive no extra delay.
- Madlions transient report failures back off 2, 4, 8, 16, 32 and 64 ms,
  remain capped at 64 ms and reset after success.
- Wooting, Razer and NuPhy report-stream behavior is unchanged.
- Telemetry identifies deadline-paced production workers separately from an
  explicitly unthrottled diagnostic build.
