User constraint
---------------
No UAP-routed keyboard and no pair of identical UAP devices is available.
D-022 therefore requires exact production-code properties, multiple compilers,
sanitizers, the real ABI/build and an available-device production regression.
This evidence does not claim a physical UAP USB or firmware measurement.

Production contract
-------------------
- Versioned domain: HallJoy/UAP/device-id/v2.
- Path identity inputs: normalized HID interface path, VID, PID, usage page,
  usage. Enumeration occurrence is ignored.
- ASCII path case and slash direction normalize identically.
- Every string field is length-framed before hashing.
- Missing path falls back to metadata plus occurrence and is not flagged
  DuplicateSafeId in telemetry or dense snapshots.
- UI prints the 64-bit ID and stable-path versus fallback status.
- Serial-less devices moved between ports follow the interface/port path.

vectors are the practical regression proof. Driver-specific HID path changes
and physical USB latency remain outside a software-only claim.
