- MAD68, Hex80, Addressed, SparkLink and Sayo perform foreign-claim checks
  after SetupAPI path discovery and before any HID open.
- Each backend claims the exact path it proved; Sayo claims every reader path.
- Soup generated patch and locked overlay call the plugin-owned shared hook
  before CreateFileW. No duplicate substring/hash implementation remains.
