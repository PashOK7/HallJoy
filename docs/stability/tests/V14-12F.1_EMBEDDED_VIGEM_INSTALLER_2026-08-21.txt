Security and UX contract
------------------------
- Exact installer is linked as RCDATA; no end-user runtime download occurs.
- Build checks source size, SHA-256 and valid Nefarius Authenticode.
- Runtime checks embedded size/SHA before extraction.
- Extraction uses a CSPRNG directory and CREATE_NEW file.
- Bytes are flushed before the writer transitions through a path-retaining
  bridge to a final read-only handle denying write/delete sharing.
- Locked bytes are re-hashed and Authenticode is checked through the same
  handle. A non-executing READ|EXECUTE open proves launch compatibility.
- The same locked file is re-hashed immediately before explicit user-approved
  runas. The lock remains held until installer completion.
- Wait is message-pumped and bounded to 20 minutes. Timeout does not kill the
  installer; cleanup is scheduled for reboot.
- UI actions are explicit: Install, open official release, continue without
  output. Ctrl+C/copy-error URL extraction is not required.
- Successful install retries backend initialization in the same process;
  restart-required and failure states are explicit.
