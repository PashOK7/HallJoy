HallJoy V14-12J / S21 unattended-soak sleep prevention
Date: 2026-08-01
Status: VERIFIED

Contract
--------
- The runner calls SetThreadExecutionState with unsigned
  ES_CONTINUOUS | ES_SYSTEM_REQUIRED before HallJoy starts.
- A rejected power request fails the qualification before HallJoy launch.
- finally always clears the thread-scoped request with ES_CONTINUOUS.
- checkpoint and summary record system_sleep_prevented.
- Manual suspend, reboot or power loss still invalidates a run.

Pilot 1
-------
Status: expected harness failure before HallJoy launch.
Cause: PowerShell interpreted raw 0x80000001 as a negative Int32 before the
UInt32 P/Invoke conversion. The checkpoint retained zero samples and false
system_sleep_prevented. No production process was started.

Correction
----------
The high-bit constants are now unsigned C# constants (0x80000001u and
0x80000000u) behind PreventSystemSleep/ClearSystemSleepPrevention wrappers.
