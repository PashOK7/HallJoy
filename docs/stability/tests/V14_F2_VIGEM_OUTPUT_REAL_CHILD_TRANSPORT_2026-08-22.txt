Implemented contract
--------------------
- The existing 640-byte shared ABI names requestedPadCount in reserved control
  capacity; configuration and Ready acknowledgement are generation-bound.
- One VigemChildTransport owns one client and a fixed array of four targets.
- Start validates 1..4 pads, connects, adds every target and explicitly submits
  a neutral report to every target before Ready.
- Apply acknowledges a complete shared snapshot only after every selected real
  vigem_target_x360_update succeeds.
- Stop visits every target for neutral, then every target for remove/free, then
  disconnect/free. It keeps the first exact ViGEm phase/error while continuing
  cleanup. Clean stop requires both complete neutral and complete removal.
- A hung SDK call remains inside the already-proved process/job boundary.
- Real mode is accepted by the exact early HallJoy output host. Simulator fake
  modes remain simulator-only. Production self-test entry remains rejected.
- backend.cpp was not changed and still owns the only normal production route.
