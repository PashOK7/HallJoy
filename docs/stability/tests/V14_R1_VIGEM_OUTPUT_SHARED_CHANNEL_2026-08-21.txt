ABI result:
  SharedStateV1 is standard-layout, trivially copyable, 64-byte aligned and
  exactly 640 bytes. It contains no pointer, HANDLE, STL container or ViGEm SDK
  type. XusbReportV1 is exactly 12 bytes and has explicit fixed-width fields.

Concurrency contract:
  Three 128-byte slots use atomic Empty/Writing/Ready/Reading ownership.
  Payload bytes are accessed only while exclusively owned. Realtime publication
  performs a bounded scan and contains no wait, sleep, mutex or condition
  variable. A delayed child causes latest-value coalescing by reclaiming Ready,
  never a Reading slot. Child reads reject stale output generations.

Design correction:
  The proposed plain-payload seqlock was rejected before production use because
  sequence validation can detect a collision but does not remove the formal C++
  data race caused by concurrent non-atomic payload reads and writes. Claimed
  slots preserve complete snapshots without that undefined behaviour.
