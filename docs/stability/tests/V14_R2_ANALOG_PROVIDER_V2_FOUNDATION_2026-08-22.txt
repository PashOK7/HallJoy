HallJoy V14 R2-A/B1 AnalogProviderV2 foundation evidence
Date: 2026-08-22

Scope
-----
This package establishes the production-compiled semantic contract and portable
negative gates before any UAP/native production route is migrated. It does not
change protocol bytes, source arbitration, profiles, UI or hardware claims.

Selected architecture
---------------------
- Versioned KeyIdentityV1 with distinct USB HID usage, UAP extended and
  HallJoy semantic namespaces.
- POD AnalogSnapshotHeaderV2/AnalogDeviceV2/AnalogSampleV2 contract.
- Normalized float plus optional exact raw numerator/domain.
- Independent provider/sample/value/ownership generations and timestamps.
- Explicit complete/truncated state, capacity and required counts.
- Full authoritative release-to-zero; changed-only state is not authoritative.
- Staged UAP/native adapters followed by equivalence gates; no big-bang switch.

Negative and boundary gates
---------------------------
PASS: USB keyboard usage 0xF0 and HallJoy semantic control 0xF0 are distinct.
PASS: USB Menu 07:65, USB Consumer Play/Pause 0C:CD, UAP Fn 0x409 and UAP
      OEM1 0x403 are distinct identities.
PASS: invalid namespace/page/version combinations fail closed.
PASS: adjacent raw 1/4095 and 2/4095 remain distinct even though legacy milli
      quantization maps both to zero; exact numerator/domain are retained.
PASS: legacy milli conversion carries an explicit LegacyQuantized flag.
PASS: an owned, valid, fresh zero is accepted as authoritative release.
PASS: complete 1/8/16/32-device snapshots validate.
PASS: insufficient capacity cannot claim Complete; truncation is explicit.
PASS: duplicate device identity and duplicate same-device/key samples fail;
      the same key on two distinct devices is allowed.
PASS: same-generation counters/timestamps cannot regress; sample-only progress
      does not wake realtime; value/ownership/provider-generation change does.
PASS: provider-generation wrap/regression fails closed.
