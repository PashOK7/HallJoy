HallJoy v1.4.1 R2-B2h - negotiated-capacity UAP producer evidence
Date: 2026-08-23

Scope
-----
This package removes the private Provider V2 producer's fixed eight-owner
capture window. It does not change the production output route and does not
claim that the existing fixed SharedState IPC has been replaced.

Selected design
---------------
- Query exact registry owner demand before acquiring registry/device locks.
- Grow reusable caller-owned pin/projection/lock storage before locks.
- Pin one complete ownership generation into caller-provided storage.
- Acquire the complete device lock set and release it in reverse order.
- Clear every retained shared owner reference on every exit.
- Retry bounded topology movement; reject resource-ceiling violations and
  repeated instability without truncating the authoritative capture.
- Caller output capacity controls copied output only, never producer capture
  capability.

Boundary and next gate
----------------------
The UAP producer can now capture more than eight owners coherently, but the
current monolithic analog-host SharedState is still an eight-slot transport.
Production therefore remains on the already-qualified dense compatibility
route. R2-B2i must add a separately owned, capacity-negotiated, parent-read-only
Provider V2 data plane and qualify its resize/topology/restart/fault lifecycle.
Only R2-B2j may select Provider V2 output and remove the dense runtime fallback.
