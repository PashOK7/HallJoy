SCOPE
-----
This checkpoint implements and validates only the portable variable-layout and
publication contract selected by D-074. It does not create or inherit a Windows
payload mapping, change parent/child mapping rights, remove fixed SharedState
arrays, switch the live shadow, publish Provider V2 to XUSB, or authorize a user
build. Those boundaries remain B2i-b, B2i-c and B2j respectively.

COMPARED IMPLEMENTATIONS
------------------------
1. Raise the fixed device/sample constants: rejected; only moves the cliff.
2. Resize the monolithic bidirectional SharedState mapping: rejected; Windows
   mappings do not resize in place and this retains coupled lifecycle/rights.
3. Copy every frame through pipe/RPC: rejected for high-rate payload because it
   adds serialization, copying, queue capacity and backpressure per generation.
4. Separate parent-owned double-buffered mapping with a parent-read-only payload
   view and child-writable view: selected; Windows lifecycle follows in B2i-b.
