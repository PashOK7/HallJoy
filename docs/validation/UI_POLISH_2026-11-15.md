Date: 2026-11-15. Branch: `fix/windows-build-portability`, based on accepted
upstream main `35ba83ac1f42fe849bd896721503a880a8cf4c61`. Denis requested these UI
changes after testing the initial language dropdown, and explicitly authorized
a local commit. Remote repository writes remain his manual operation.

## Changes

- `support_banner_session.h` implements process-local dismissal with a 60,000 ms
  delay. The painted close button is to the right of the QR code, appears after
  the delay and collapses the invitation through the ordinary page layout.
  Reconnection and language changes preserve dismissal; a new process starts
  with the invitation and delay again. One timer wake-up replaces a countdown.
- Operational warnings remain visible: communication problems, another app
  holding the keyboard, unsupported/research-only/unavailable hardware and known
  limited firmware. A new such warning can replace a dismissed invitation.
  The existing Global settings Discord card stays available.
- Profiles Clear buttons allocate space from the content's right edge, measure
  the localized caption and preserve at least eight logical pixels before the
  scrollbar track. Shortcut buttons use the remaining width. Profile selector
  mode labels are measured; the controls have insets and consistent corners.
- The shared dropdown renderer clips both its fill and arrow hover fill to the
  rounded outline, leaving the panel background visible in the outer corners.
- `ui_font.h` requests installed Malgun Gothic / Yu Gothic UI / Microsoft YaHei
  UI for Korean / Japanese / Simplified Chinese. It caches GDI fonts, scales body
  sizes for DPI and preserves other-language fonts. Native labels protect this
  choice from callers' later stock-font assignment, including during startup;
  switching back to English restores the stock font. Shared retained text,
  dropdowns, tooltips and GDI+ UI text use the family choice.

No font files are embedded, copied or downloaded. These are proprietary Windows
system fonts, used for rendering under Microsoft's
[documented system-font use](https://learn.microsoft.com/en-us/typography/fonts/font-faq),
not fonts relicensed by HallJoy. See the
[language and font guide](../development/INTERFACE_LANGUAGES.md).
