# NA87: один расширенный диагностический пакет

> Этот standalone-сценарий отклонён владельцем. Актуальный тест — обычный HallJoy.exe
> с автоматической диагностикой; см. docs/current/IROK_NA87_HALLJOY_DIAGNOSTIC_2026-09-13.md.
> protocol.h используется интеграцией, старый пакет не передавать.

Уточнение владельца 2026-09-13: тестировщика с ND75 нет, есть с обычной NA87.
Минимальный inventory недостаточен: нужен один пакет с несколькими стратегиями
и сценариями, чтобы не выдавать новую сборку для каждой гипотезы.

Пакет собран, самопроверки и упаковка проверены. Итог, единственный архив
для передачи и SHA256: docs/current/IROK_NA87_SINGLE_PACKAGE_TEST_2026-09-13.md. Отправлять прежний ND75 diagnostic как NA87
нельзя: он проверяет другую модель и не реализует этот план.

План: metadata всех HID-коллекций семейства; ограниченные по времени пробы
identity/capability на подходящих vendor-интерфейсах и объявленных report IDs;
interrupt/control output, shared/exclusive доступ. Аналоговые сценарии только
после ответа M484/GK8260HERGB. Собирать сырые ответы и время, не превращая их
в виртуальный геймпад. Чтение карты и штатных настроек, обучение WASD,
одиночная/общая/групповая/сменяющаяся подписка, неподвижное удержание после
переподписки, отпускания, финальный покой, повторное подключение.

Разрешённые формы TX перечислены в protocol.h. Настройки, калибровка и flash
не записываются. Приостановленные чтения вне штатной таблицы сюда не входят.
Контрольная подписка изменяет только временную маску; на выходе — отписка.
Не обещать полноту всех неизвестных протоколов и аппаратный PASS до результатов.
